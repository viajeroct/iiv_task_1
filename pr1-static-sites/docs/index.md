# Публикация результатов исследований

Сайт собран генератором статических сайтов **MkDocs** с темой **Material** и
опубликован на учебном хостинге ИТМО. Сборка выполняется в режиме
`mkdocs build --strict`: битая внутренняя ссылка или предупреждение
останавливают сборку.

## Что на сайте

- [T1. Сравнение генераторов статических сайтов](t1.md) — матрица
  «критерий × генератор» и вывод о выборе инструмента.
- [P2. Страница-стресс-тест научного контента](p2.md) — формула, таблица,
  графики, листинг кода, библиография и сноски.
- [ПР3. Проект экспериментального стенда](pr3.md) — критерии научности,
  RQ и гипотезы, план эксперимента.
- [ПР4. Реализация экспериментального стенда](pr4.md) — архитектура,
  запуск одной командой, анализ результатов.
- [Отчёты](reports.md) — исходные документы по практическим работам.

## Воспроизведение

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
mkdocs build --strict
mkdocs serve
```

Исходный код: [github.com/viajeroct/iiv_task_1](https://github.com/viajeroct/iiv_task_1).
