# Навык: ежедневный дайджест публикаций

## Назначение
Найти новые публикации по теме ВКР и прислать краткий дайджест.

## Условия срабатывания
- Расписание: ежедневно в 08:00.
- Команда пользователя: «дайджест» или «что нового по теме».

## Процедура
1. Прочитать USER.md и MEMORY.md, получить список тем и уже отправленных работ.
2. Для каждой темы выполнить поиск по arXiv за последние 7 дней (не более 20 результатов).
3. Прочитать аннотации и оценить по смыслу, относится ли работа к теме. Оставить релевантные.
4. Исключить работы, уже присланные ранее (список в MEMORY.md).
5. Для каждой работы указать: название, авторов, ссылку, 1–2 предложения о сути и релевантности.
6. Отправить дайджест в Telegram, добавить отправленные работы в MEMORY.md.

## Обработка отказов (обязательно)
- Источник недоступен: сообщить «arXiv недоступен, дайджест не сформирован», причину и время. Не подставлять результаты из памяти.
- Пустой результат: сообщить «новых релевантных работ нет».
- Превышен лимит запросов: сообщить, остановиться, повторить в следующий запуск.
- Запрещено указывать работу, которую не удалось открыть по ссылке.
