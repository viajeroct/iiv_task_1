# ПР2. Агент для решения научных задач

Развёртывание Hermes Agent в Docker Compose: шлюз Telegram, файловая
память, навыки и планировщик.

## Состав

```
compose.yaml            описание контейнера, лимиты и логирование
.env.example            шаблон переменных окружения
skills/daily-digest.md  навык ежедневного дайджеста публикаций
```

## Настройка

1. Создать бота через [@BotFather](https://t.me/BotFather) и получить токен.
2. Узнать свой числовой идентификатор пользователя Telegram.
3. Выбрать LLM-провайдера с OpenAI-совместимым API и получить ключ.
4. Заполнить `.env`:

```bash
cp .env.example .env
# TELEGRAM_BOT_TOKEN=...
# TELEGRAM_ALLOWED_USERS=<числовой id>
# OPENROUTER_API_KEY=...
chmod 600 .env
```

5. Запустить:

```bash
docker compose up -d
docker compose logs -f
```

Контрольные признаки успешного старта — ненулевое число загруженных
навыков и подключённый шлюз Telegram.

## Ограничение доступа

В `TELEGRAM_ALLOWED_USERS` указывается только собственный идентификатор.
Режим «разрешить всем» не включается. Токены и ключи хранятся в `.env`
вне репозитория.

## Навык

`skills/daily-digest.md` — ежедневный обзор новых публикаций по теме
ВКР: условия срабатывания, пошаговая процедура, обработка отказов
и формат результата.
